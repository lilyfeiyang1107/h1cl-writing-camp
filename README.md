# 心境实验室 · H1 华文写作训练营

面向新加坡 JC 学生的心理描写练习网站。三个原创主题均提供完整三级训练：词汇赏析、双角色独白、心理转折创作；包含情感温度计、可暂停的60分钟计时、逐关奖励、浏览器自动保存和作品/文字证书下载。

## 本地运行

无需安装依赖。使用 Python 3：

```sh
cd /workspace/h1cl-writing-camp
python3 -m http.server 3000 --bind 0.0.0.0
```

在浏览器访问服务器的3000端口。也可以部署到任何静态网站托管服务（例如 GitHub Pages），入口为 `index.html`。

## 使用说明

每个主题独立保存进度。第一关点击三处心理描写；第二关分别完成两个角色的独白（每段至少60字）；第三关完成至少150字的创作及三项自查，解锁成果下载。计时器为练习提示，不强制交卷。阶段按钮允许自由查看各关。

作品保存在当前浏览器的 localStorage 中，不会上传；清理浏览器数据会丢失作品，请下载备份。所有情境采用原创文字分镜，不含电影或教师视频。反馈为固定教学提示与完成度检查，不含AI评分。可选网络字体无法加载时使用系统字体，不影响功能。
